# Hotel Booking Console Demo

[Open the interactive demo](https://yinl-k.github.io/hotel-booking-console-demo/)

A desktop demo of a hotel search and comparison workflow. Select check-in and check-out dates, mark a search center on the Beijing map, then compare nearby hotels, room prices, and cancellation rules.

The catalog contains 48 fictional hotels. Quotes and rules are generated for the demo. The map uses bundled geographic data.

Open **index.html** in a browser with WebGL. To rebuild after changing the source, run **node build.cjs**.

The map uses [MapLibre GL JS 4.7.1](vendor/LICENSE.txt). The Beijing basemap is derived from [OpenStreetMap contributors](https://www.openstreetmap.org/copyright) via [Geofabrik](https://download.geofabrik.de/asia/china/beijing.html). [Basemap data and license](data/README.md).
