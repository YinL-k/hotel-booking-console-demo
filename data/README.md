# Beijing basemap data

**beijing.json.gz** contains six GeoJSON feature collections derived from the Geofabrik Beijing extract. The bundled data is available under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Data copyright © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).

The clipping and simplification script is available in the [map demo repository](https://github.com/YinL-k/hotel-map-smooth-zoom/blob/main/scripts/extract-map.cjs).
